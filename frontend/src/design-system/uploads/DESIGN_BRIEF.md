# DESIGN_BRIEF.md — Claude Design용 UI 브리프

> **목적**: `DESIGN.md`의 9번 UI 정보 구조를 화면으로 구현하기 위한 디자인 브리프.
> 각 탭에 **어떤 컴포넌트가 필요하고, 무슨 데이터를 담으며, 어떻게 배치되면 좋을지**를 구체화한다.
> 색·타이포 등 구체 비주얼은 Claude Design에서 확정 — 본 브리프는 **필수 제약 + 방향성**만 고정하고 나머지는 열어둔다.

---

## 0. 제품 한 줄 정의

국내 주식 데이트레이딩용 **매매신호 대시보드**. 종목을 검색하면 여러 지표를 종합해 매수/매도 방향성을 주되, **근거(지표별 기여도)를 전부 공개**하고 **가중치를 사용자가 조절**할 수 있는 투명한 도구. 6개 탭으로 목적별 화면 분리.

---

## 1. 디자인 방향 (고정 제약 + 열린 선택)

### 🔒 고정 제약 (반드시 지킬 것)
- **상승/매수 = 빨강, 하락/매도 = 파랑** (국내 시장 관습. 서구식 초록/빨강과 반대이므로 주의). 중립 = 회색.
- **한글 가독성 우선** — 숫자·지표가 빽빽하므로 판독성이 최우선.
- **정보 밀도 편차 허용** — 탭마다 밀도가 다름(탭1은 여백 많고 시원하게 / 탭2·3은 밀도 높게). 이 편차를 디자인이 수용해야 함.

### 🔓 Claude Design에서 정할 것
- 전체 색 팔레트(위 매수/매도 색은 고정, 나머지 톤은 자유)
- **라이트/다크 모드** — 트레이딩 툴 특성상 다크 우선 or 양쪽 지원 검토 권장
- 타이포(제안: 숫자 판독성 좋은 고정폭 계열 + 본문 Pretendard)
- 카드/보더/그림자 등 컴포넌트 스타일
- 차트 비주얼 톤

---

## 2. 공용 컴포넌트 (여러 탭에서 재사용)

디자인 일관성을 위해 아래는 **재사용 컴포넌트**로 설계.

| 컴포넌트 | 설명 | 표시 데이터 |
|----------|------|-------------|
| **종목 검색바** | 상단 고정. 티커/종목명 입력, 자동완성 | 종목 코드·명 |
| **종목 헤더** | 검색 종목의 요약 스트립 | 현재가, 등락률(±%), 거래량, 시가총액 — 등락 색상 규칙 적용 |
| **방향성 게이지** | 5단계 반원/게이지 | 적극매도 · 매도 · 중립 · 매수 · 적극매수 + 최종 스코어(-100~100) |
| **기여도 막대** | 지표별 +/- 기여도 수평 막대 | 지표명, 기여 점수(±), 가중치 |
| **캔들 차트** | 캔들스틱 + 오버레이 토글 | OHLCV, 이평선/VWAP/볼린저 |
| **지표 테이블** | 지표 현재값·신호 나열 | 지표명, 값, 신호(매수/중립/매도) |
| **탭 네비게이션** | 6개 탭 전환 | 아이콘 + 라벨 |

---

## 3. 탭별 상세 명세

각 탭: **목적 / 필요한 컴포넌트 / 레이아웃 힌트 / 인터랙션**.

---

### 탭 1 — 종합 신호 _(한눈에 답)_
**목적**: "사? 팔아?"에 3초 안에 답. 결론 우선, 근거는 그 아래.

**컴포넌트**
- 종목 헤더 (공용)
- **대형 방향성 게이지** — 이 탭의 히어로. 화면에서 가장 큰 시각 요소
- 기여도 요약 막대 (공용, 상위 4~5개만)
- 미니 캔들 + VWAP 차트 (축소판)
- **신호 히스토리 타임라인** — 당일 신호 변화(매수→중립→매수 등)를 시간축으로. "방금 바뀐 신호인지" 판별용

**레이아웃 힌트**: 위→아래로 `결론(게이지) → 근거(기여도) → 참고(미니차트·히스토리)`. 여백 넉넉하게, 한 화면에 스크롤 최소.

**인터랙션**: 기여도 막대 클릭 시 해당 지표의 탭 2로 이동(딥링크).

---

### 탭 2 — 기술적 분석 _(차트 딥다이브)_
**목적**: 차트를 파고드는 화면. 정보 밀도 높아도 됨.

**컴포넌트**
- **타임프레임 토글** — 1분 / 5분 / 일봉 (세그먼트 컨트롤)
- **메인 캔들 차트** (크게) + 오버레이 토글(이평선·VWAP·볼린저)
- 거래량 바 (메인차트 하단 서브패널)
- **오실레이터 서브차트** — RSI / MACD / 스토캐스틱 (접기/펼치기)
- 지표 현재값·신호 테이블 (공용)

**레이아웃 힌트**: 차트가 화면 대부분을 차지. 메인 캔들(상) → 거래량(중) → 오실레이터(하) 세로 스택. 우측 또는 하단에 지표 테이블.

**인터랙션**: 오버레이 on/off 토글, 서브차트 추가/제거, 차트 확대·이동(팬/줌).

---

### 탭 3 — 수급 _(돈의 흐름)_ ⭐
**목적**: 국내 단타의 핵심. 누가 사고파는지.

**컴포넌트**
- **외국인·기관 순매수 추이** 차트 (일별/누적 토글)
- 프로그램 매매 동향
- **체결강도 미터** — 매수/매도 체결 비율 (게이지 or 좌우 분할 바)
- **호가창(Level 2)** — 10호가, 매수/매도 잔량을 수평 막대로 시각화 (매도=파랑 위, 매수=빨강 아래)
- **거래원 테이블** — 창구별 매수/매도 상위

**레이아웃 힌트**: 호가창은 세로로 긴 형태 → 좌측 컬럼 고정 배치. 우측에 수급 추이 차트 + 체결강도 + 거래원. 2컬럼 구성 적합.

**인터랙션**: 순매수 차트 일별/누적 전환, 거래원 테이블 정렬.

---

### 탭 4 — 리스크 / 전략 _(실전 매매 계획)_ ⭐
**목적**: 신호기를 넘어 매매 계획 도구로. 손절·목표·수량 계산.

**컴포넌트**
- **진입가 입력** 폼 (현재가 자동 채움 + 수정 가능)
- **손절가/목표가 카드** — ATR 기반 자동 제안 (여러 배수 옵션: 1×/1.5×/2× ATR)
- **손익비(R:R) 시각화** — 진입·손절·목표를 하나의 수직 바에 표시, 위험:보상 비율 강조
- **포지션 사이징 계산기** — 계좌 크기 + 감당 리스크(%) 입력 → 매수 수량·투입금액 산출

**레이아웃 힌트**: "계산기" 성격. 좌측 입력 폼 → 우측 결과 카드가 실시간 갱신되는 형태. 입력→결과 흐름이 명확하게.

**인터랙션**: 입력값 변경 시 결과 즉시 재계산.

---

### 탭 5 — 관심종목 / 스크리너 _(종목 발굴)_ (v2)
**목적**: 한 종목이 아니라 여러 종목을 한눈에.

**컴포넌트**
- **워치리스트** — 종목별 신호 뱃지(색상 라벨) 달린 리스트/카드
- **조건 빌더** — 지표 조건 조합 UI (예: VWAP 상향돌파 AND 거래량 급증 AND RSI 다이버전스)
- **결과 테이블** — 조건 충족 종목, 정렬 가능(스코어·등락률·거래량)

**레이아웃 힌트**: 좌측 워치리스트/조건 → 우측 결과 테이블. 리스트·테이블 중심.

**인터랙션**: 조건 추가/삭제, 결과 행 클릭 시 탭 1로 해당 종목 로드.

> v2 기능. 다종목 조회로 API 호출이 많아 실전 계좌·최적화 후 구현.

---

### 탭 6 — 설정 _(커스터마이징)_ ⭐
**목적**: 투명성의 완성. 사용자가 스코어링을 직접 튜닝.

**컴포넌트**
- **가중치 슬라이더** — 지표(수급·추세·모멘텀·거래량·변동성)별 슬라이더. 합계 100% 시각화(도넛 or 스택 바)
- **프리셋 선택** — "수급 중시 / 모멘텀 중시 / 균형" 등 원클릭 프리셋
- **알림 임계값** 설정 (스코어 ±몇 이상일 때 알림)
- **지표 파라미터** 입력 (RSI 기간, 이평선 기간 등)

**레이아웃 힌트**: 설정 폼. 슬라이더 조절 시 **미니 미리보기**(예시 종목의 신호가 어떻게 바뀌는지)가 실시간 반영되면 이상적.

**인터랙션**: 슬라이더 드래그 → 실시간 반영, 프리셋 적용, 저장/초기화.

---

## 4. 화면 상태 (모든 탭 공통 고려)

디자인 시 아래 상태를 함께 정의.
- **빈 상태**: 종목 미선택 시 안내 화면
- **로딩**: 데이터 조회 중 스켈레톤
- **에러**: API 실패·호출 제한 초과 시 메시지
- **장 시간 표시**: 장중/장마감/시간외 상태 배지 (데이터 신선도 안내)

## 5. Claude Design에 넘길 때 결정할 것 (체크리스트)

- [ ] 라이트/다크 모드 (다크 우선 여부)
- [ ] 전체 색 팔레트 (매수 빨강/매도 파랑은 고정, 배경·강조색은 자유)
- [ ] 타이포 — 숫자용 폰트 / 본문 폰트
- [ ] 데이터 밀도 톤 (시원하게 vs 정보 빽빽하게 — 탭별로 다르게 가능)
- [ ] 차트 스타일 방향 (미니멀 라인 vs 정통 트레이딩 차트 룩)
- [ ] 탭 네비게이션 위치 (상단 vs 좌측 사이드바)
- [ ] 데스크톱 전용 vs 반응형(모바일 대응) 여부

## 6. 우선 디자인 순서 (제안)

DESIGN.md 로드맵과 맞춤:
1. **공용 컴포넌트** 먼저 (게이지·기여도 막대·종목 헤더·캔들차트) — 나머지 탭이 이걸 재사용
2. **탭 1** (종합 신호) — 제품 얼굴
3. **탭 2·3** (기술·수급) — 코어
4. **탭 4·6** (리스크·설정) — 차별화
5. **탭 5** (스크리너) — v2
