# DESIGN_BRIEF.md — Claude Design용 UI 브리프

> **목적**: `DESIGN.md`의 UI 정보 구조를 화면으로 구현하기 위한 디자인 브리프.
> 각 탭에 **어떤 컴포넌트가 필요하고, 무슨 데이터를 담으며, 어떻게 배치되면 좋을지**를 구체화한다.
> 색·타이포 등 구체 비주얼은 Claude Design에서 확정 — 본 브리프는 **필수 제약 + 방향성**만 고정하고 나머지는 열어둔다.

---

## 0. 제품 한 줄 정의

국내 주식 데이트레이딩용 **매매신호 대시보드**. 종목을 검색하면 여러 지표를 종합해 매수/매도 방향성을 주되, **근거(지표별 기여도)를 전부 공개**하고 **가중치를 사용자가 조절**할 수 있는 투명한 도구. **시장 전체(매크로) 국면**을 함께 본다. 탭 5개 + 설정 아이콘으로 목적별 화면 분리.

---

## 1. 디자인 방향 (고정 제약 + 열린 선택)

### 🔒 고정 제약 (반드시 지킬 것)
- **상승/매수 = 빨강, 하락/매도 = 파랑** (국내 시장 관습. 서구식 초록/빨강과 반대이므로 주의). 중립 = 회색.
- **리스크온 = 빨강 계열, 리스크오프 = 파랑 계열** (위 규칙과 일관).
- **한글 가독성 우선** — 숫자·지표가 빽빽하므로 판독성이 최우선.
- **정보 밀도 편차 허용** — 탭마다 밀도가 다름(탭1은 시원하게 / 탭2·3·5는 밀도 높게).

### 🔓 Claude Design에서 정할 것
- 전체 색 팔레트(매수/매도 색은 고정, 나머지 톤은 자유)
- **라이트/다크 모드** — 트레이딩 툴 특성상 다크 우선 권장
- 타이포(제안: 숫자 판독성 좋은 고정폭 계열 + 본문 Pretendard)
- 카드/보더/그림자 등 컴포넌트 스타일
- 차트 비주얼 톤
- 탭 네비 위치(상단 바 vs 좌측 사이드바)

---

## 2. 전역 레이아웃

```
┌──────────────────────────────────────────────┐
│  [종목 검색바]                        [⚙ 설정] │  ← 상단 고정
├──────────────────────────────────────────────┤
│  탭 바: 종합신호 · 기술 · 수급 · 리스크 · 매크로 · 스크리너 │
├──────────────────────────────────────────────┤
│                                                │
│              (선택된 탭 콘텐츠)                  │
│                                                │
└──────────────────────────────────────────────┘
```

- **설정(⚙)**은 탭이 아니라 우측 상단 아이콘 → 모달/사이드 패널.
- 종목 검색바는 항상 상단 고정(어느 탭에서든 종목 전환 가능).

---

## 3. 공용 컴포넌트 (여러 탭에서 재사용)

| 컴포넌트 | 설명 | 표시 데이터 |
|----------|------|-------------|
| **종목 검색바** | 상단 고정. 티커/종목명 입력, 자동완성 | 종목 코드·명 |
| **종목 헤더** | 검색 종목 요약 스트립 | 현재가, 등락률(±%), 거래량, 시가총액 — 등락 색상 규칙 |
| **방향성 게이지** | 5단계 반원/게이지 | 적극매도·매도·중립·매수·적극매수 + 스코어(-100~100) |
| **기여도 막대** | 지표별 +/- 기여도 수평 막대 | 지표명, 기여 점수(±), 가중치 |
| **캔들 차트** | 캔들스틱 + 오버레이 토글 | OHLCV, 이평선/VWAP/볼린저 |
| **지표 테이블** | 지표 현재값·신호 나열 | 지표명, 값, 신호(매수/중립/매도) |
| **시장 상태 표시** | 리스크온/오프 종합 판정 배지 | 탭1 배너 & 탭5 헤더에서 공용 |
| **탭 네비게이션** | 5개 탭 전환 | 아이콘 + 라벨 |

---

## 4. 탭별 상세 명세

각 탭: **목적 / 필요한 컴포넌트 / 레이아웃 힌트 / 인터랙션**.

---

### 탭 1 — 종합 신호 _(한눈에 답)_
**목적**: "사? 팔아?"에 3초 안에 답. 결론 우선, 근거는 그 아래.

**컴포넌트**
- **시장 상태 배너** (최상단) — "시장 리스크온" 등 한 줄 요약 + 코스피/코스닥 등락. 클릭 시 탭 5(매크로)로 이동
- 종목 헤더 (공용)
- **대형 방향성 게이지** — 이 탭의 히어로. 가장 큰 시각 요소
- 기여도 요약 막대 (공용, 상위 4~5개)
- 미니 캔들 + VWAP 차트 (축소판)
- 신호 히스토리 타임라인 — 당일 신호 변화

**레이아웃 힌트**: 위→아래로 `시장배너(얇게) → 결론(게이지) → 근거(기여도) → 참고(미니차트·히스토리)`. 여백 넉넉하게, 스크롤 최소. **배너는 얇게** — 주인공은 게이지.

**인터랙션**: 배너 클릭→탭5, 기여도 막대 클릭→탭2 해당 지표.

---

### 탭 2 — 기술적 분석 _(차트 딥다이브)_
**목적**: 차트를 파고드는 화면. 정보 밀도 높아도 됨.

**컴포넌트**
- **타임프레임 토글** — 1분 / 5분 / 일봉 (세그먼트 컨트롤)
- **메인 캔들 차트** (크게) + 오버레이 토글(이평선·VWAP·볼린저)
- 거래량 바 (하단 서브패널)
- **오실레이터 서브차트** — RSI / MACD / 스토캐스틱 (접기/펼치기)
- 지표 현재값·신호 테이블 (공용)

**레이아웃 힌트**: 차트가 화면 대부분. 메인 캔들(상)→거래량(중)→오실레이터(하) 세로 스택. 우측/하단에 지표 테이블.

**인터랙션**: 오버레이 on/off, 서브차트 추가/제거, 팬/줌.

---

### 탭 3 — 수급 _(돈의 흐름)_ ⭐
**목적**: 국내 단타의 핵심. 누가 사고파는지.

**컴포넌트**
- **외국인·기관 순매수 추이** 차트 (일별/누적 토글)
- 프로그램 매매 동향
- **체결강도 미터** — 매수/매도 비율 (게이지 or 좌우 분할 바)
- **호가창(Level 2)** — 10호가, 잔량 수평 막대 (매도=파랑 위, 매수=빨강 아래)
- **거래원 테이블** — 창구별 매수/매도 상위

**레이아웃 힌트**: 호가창은 세로로 긴 좌측 컬럼 고정. 우측에 수급 추이 + 체결강도 + 거래원. 2컬럼 적합.

**인터랙션**: 순매수 일별/누적 전환, 거래원 정렬.

---

### 탭 4 — 리스크 / 전략 _(실전 매매 계획)_ ⭐
**목적**: 신호기를 넘어 매매 계획 도구로.

**컴포넌트**
- **진입가 입력** 폼 (현재가 자동 채움 + 수정 가능)
- **손절가/목표가 카드** — ATR 기반 자동 제안 (1×/1.5×/2× ATR)
- **손익비(R:R) 시각화** — 진입·손절·목표를 수직 바에 표시
- **포지션 사이징 계산기** — 계좌 크기 + 리스크(%) → 매수 수량·투입금액

**레이아웃 힌트**: "계산기" 성격. 좌측 입력 → 우측 결과 카드 실시간 갱신.

**인터랙션**: 입력 변경 시 결과 즉시 재계산.

---

### 탭 5 — 매크로 / 시장 _(숲을 보는 화면)_ ⭐ 신규
**목적**: 종목과 무관하게 오늘 시장이 리스크온/오프인지. 장 시작 전 브리핑.

**컴포넌트**
- **시장 국면 종합 판정** (최상단) — 리스크온/중립/리스크오프 크게. 탭1 배너와 동일 로직
- **국내 지수 카드** — 코스피·코스닥 (지수·등락·상승/하락 종목 수)
- **해외 증시 카드** — 간밤 S&P·나스닥 + 야간 선물
- **환율·금리 카드** — 원/달러, 국고채·미국채
- **시장 수급** — 외국인·기관 시장 전체 순매수
- **변동성·심리** — VIX, 공포·탐욕 지수 (게이지)
- **업종 히트맵** — 오늘 강한/약한 섹터 (색상 그리드)

**레이아웃 힌트**: 카드 그리드(대시보드형). 상단에 종합 판정 크게 → 그 아래 지표 카드들. 각 카드에 **기준 시점(as_of) 라벨** 필수 — 해외는 전일/야간, 국내는 실시간이라 신선도가 다름.

**인터랙션**: 카드 클릭 시 상세(선택), 히트맵 섹터 클릭 시 관련 종목(v2).

---

### 탭 6 — 관심종목 / 스크리너 _(종목 발굴)_ (v2 데이터)
**목적**: 여러 종목을 한눈에.

**컴포넌트**
- **워치리스트** — 종목별 신호 뱃지(색상 라벨) 리스트/카드
- **조건 빌더** — 지표 조건 조합 (예: VWAP 상향돌파 AND 거래량 급증 AND RSI 다이버전스)
- **결과 테이블** — 조건 충족 종목, 정렬(스코어·등락률·거래량)

**레이아웃 힌트**: 좌측 워치리스트/조건 → 우측 결과 테이블.

**인터랙션**: 조건 추가/삭제, 결과 행 클릭 시 탭1로 종목 로드.

> UI는 선구현, 데이터 연동은 실전 계좌·최적화 후.

---

### ⚙ 설정 _(탭 아님 — 모달/패널)_ ⭐
**목적**: 투명성의 완성. 사용자가 스코어링을 직접 튜닝.

**컴포넌트**
- **가중치 슬라이더** — 지표(수급·추세·모멘텀·거래량·변동성)별. 합계 100% 시각화(도넛/스택 바)
- **프리셋 선택** — 수급 중시 / 모멘텀 중시 / 균형
- **시장 국면 반영 토글** — 매크로를 종목 스코어에 결합할지 on/off
- **알림 임계값** 설정
- **지표 파라미터** (RSI 기간, 이평선 기간 등)

**레이아웃 힌트**: 우측 상단 ⚙ → 모달 or 사이드 패널. 슬라이더 조절 시 **미니 미리보기**(예시 종목 신호 변화) 실시간 반영이 이상적.

**인터랙션**: 슬라이더 드래그→실시간 반영, 프리셋 적용, 저장/초기화.

## 5. 화면 상태 (모든 탭 공통 고려)

- **빈 상태**: 종목 미선택 시 안내 (단, 탭5 매크로는 종목 없이도 항상 표시)
- **로딩**: 데이터 조회 중 스켈레톤
- **에러**: API 실패·호출 제한 초과 메시지
- **장 시간 표시**: 장중/장마감/시간외 배지 + 데이터 기준 시점

## 6. Claude Design에 넘길 때 결정할 것 (체크리스트)

- [ ] 라이트/다크 모드 (다크 우선 여부)
- [ ] 전체 색 팔레트 (매수 빨강/매도 파랑 고정, 배경·강조색 자유)
- [ ] 타이포 — 숫자용 / 본문
- [ ] 데이터 밀도 톤 (탭별로 다르게 가능)
- [ ] 차트 스타일 (미니멀 라인 vs 정통 트레이딩 룩)
- [ ] 탭 네비 위치 (상단 vs 좌측 사이드바)
- [ ] 데스크톱 전용 vs 반응형

## 7. 우선 디자인 순서 (제안)

1. **공용 컴포넌트** (게이지·기여도 막대·종목 헤더·캔들차트·시장배지)
2. **탭 1** (종합 신호) — 제품 얼굴
3. **탭 2·3** (기술·수급) — 코어
4. **탭 5** (매크로) — 시장 맥락
5. **탭 4 + 설정** (리스크·커스터마이징) — 차별화
6. **탭 6** (스크리너) — v2
