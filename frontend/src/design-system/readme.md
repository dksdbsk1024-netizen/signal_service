# 단기매매 신호 대시보드 — 디자인 시스템

## 제품 개요

국내 주식 **데이트레이딩용 매매신호 대시보드**. 종목을 검색하면 여러 지표를 종합해 매수/매도 방향성을 제시하되, 근거(지표별 기여도)를 전부 공개하고 가중치를 사용자가 직접 조절할 수 있는 투명한 트레이딩 툴. 탭 바는 매매 동선 순서로 5개: ① 종합 신호 ② 기술적 분석 ③ 수급 ④ 리스크/전략 ⑤ 관심종목/스크리너. 설정은 매매 중 자주 열지 않는 화면이라 탭 바에서 빼고, 우측 상단 톱니바퀴 아이콘 → 우측 슬라이드 패널로 옮겼다(내용은 그대로: 가중치 슬라이더·프리셋·지표 파라미터·알림 임계값).

**소스 자료**: `uploads/DESIGN_BRIEF.md` (사용자 제공, 전체 UI 명세 — 6개 탭의 목적/컴포넌트/레이아웃/인터랙션을 정의). 별도 코드베이스나 Figma는 제공되지 않았다. 색·타이포·컴포넌트 스타일은 브리프의 고정 제약(매수=빨강/매도=파랑, 다크 우선, 판독성 최우선) 안에서 이 디자인 시스템이 새로 정의했다.

## 디자인 방향 — "Terminal Slate"

3개 팔레트 방향(A. Terminal Slate — 냉정한 트레이딩뷰 톤 / B. Carbon Amber — 카본블랙+골드 / C. Deep Navy — 프리미엄 핀테크)을 제시했고, **A안 + 4px radius**로 확정했다. 전문적이고 절제된 트레이딩 터미널 톤: 장식을 배제하고 숫자·신호 판독성에 모든 시각적 우선순위를 둔다.

## 고정 제약 (브리프 원문)

- **매수/상승 = 빨강, 매도/하락 = 파랑** — 국내 시장 관습, 서구식(초록/빨강)과 반대. 중립 = 회색. 모든 컴포넌트가 이 매핑을 하드코딩하므로 호출부에서 색을 지정할 필요가 없다.
- **다크 모드 우선** — 장시간 트레이딩 툴 특성상 눈이 편한 저채도 배경. 라이트 모드 토큰도 `[data-theme="light"]`로 병행 준비.
- **숫자·지표 판독성 최우선** — 모든 숫자에 `font-variant-numeric: tabular-nums` 적용, 과한 장식 배제.
- **탭별 밀도 편차 허용** — 탭1(종합신호)은 여백 많고 시원하게, 탭2·3(기술분석·수급)은 고밀도. `dense` prop으로 컴포넌트가 이 편차를 수용.
- **데스크톱 전용** — 반응형 대응 없음.

## 콘텐츠 원칙

- 모든 라벨·용어는 실제 트레이더가 쓰는 한국어 업계 용어 그대로 사용 (적극매수/매수/중립/매도/적극매도, 수급, 모멘텀, 체결강도, 호가창, R:R 등). 영어 번역이나 순화 표현을 만들지 않는다.
- 어조: 건조하고 사실 위주. 느낌표·이모지·귀여운 카피 없음. "지금 사세요!" 같은 권유형 문구 금지 — 항상 지표와 숫자로만 말한다. 단, **종목토론방(커뮤니티) 카드 안의 사용자 게시글은 예외** — 실제 트레이더들의 구어체 반말·은어를 그대로 반영해 다른 UI 카피와 명확히 구분되는 "사용자 발화" 톤을 유지한다.
- 숫자는 항상 부호(+/-)를 명시하고 3자리마다 콤마(`toLocaleString("ko-KR")`).

## 비주얼 파운데이션

- **색**: 배경은 거의 무채색에 가까운 진남색빛 다크(`--n-1 #0a0e14`)로 시작해 카드(`--n-3`)·인셋(`--n-5`)·보더(`--n-6`)로 단계적으로 밝아지는 12단 뉴트럴 스케일. 시그널 컬러(매수 빨강 `#ff5c5c`/매도 파랑 `#4d8dff`/중립 회색)는 배경·텍스트 어디에도 절대 흔들리지 않는 고정 매핑. 강조색은 시그널과 충돌하지 않도록 골드(`--accent #e8b339`) 하나만 사용 — 포커스 링, 활성 탭 언더라인, VWAP 라인 등 "방향성이 없는" 강조에만 쓴다.
- **타이포**: 본문·숫자 모두 Noto Sans KR 한 서체로 통일(가독성 좋은 한글 렌더링 + 라틴 숫자 지원 모두 우수). 숫자 컨텍스트는 `.ds-numeric` 클래스로 tabular-nums 강제.
- **여백**: 4px 베이스 그리드. 탭1은 `--space-6`~`--space-8` 위주로 넉넉하게, 탭2·3은 `--space-1`~`--space-2`로 좁혀 밀도를 높인다.
- **배경/이미지**: 풀블리드 이미지, 손그림 일러스트, 텍스처·패턴 없음. 순수 색면 + 데이터 시각화(SVG 차트/게이지)만 사용.
- **애니메이션**: 최소한만. 탭 전환 시 밑줄 색 전환(160ms, `--ease-standard`) 정도. 바운스나 화려한 트랜지션 없음 — 데이터가 튀어 보이면 안 된다.
- **호버/프레스 상태**: 호버는 표면을 한 단계 밝게(`--bg-surface` → `--bg-surface-raised`), 인터랙티브 보더는 골드 강조색으로 전환. 프레스 상태에서 축소(scale) 효과는 쓰지 않는다(숫자가 흔들려 보이는 느낌을 피하기 위함).
- **보더/그림자**: 카드 구분은 그림자보다 1px 보더(`--border-default`)가 우선. 그림자는 `--shadow-xs`~`md` 정도로 아주 미세하게, 드롭다운·팝오버 등 진짜로 뜬 레이어에만 사용.
- **코너 radius**: 4px(`--radius-md`)를 카드/버튼/인풋 기본값으로 확정. 2px/3px(xs/sm)는 태그·배지처럼 더 각진 느낌이 필요한 작은 요소, 6px(lg)는 모달/팝오버 같은 진짜로 "뜬" 레이어에만 사용해 트레이딩 터미널다운 각진 인상을 유지한다.
- **투명도/블러**: 시그널 배경(`--signal-buy-bg` 등)에 14% 알파를 사용해 컬러 텍스트와 배경이 부딪히지 않게 하는 정도로만 사용. 블러(backdrop-filter)는 쓰지 않는다.
- **레이아웃 고정 요소**: 종목 검색바 + 탭 네비게이션은 상단 고정.

## 아이코노그래피

브리프에 아이콘 시스템이 정의되어 있지 않다. 탭 네비게이션은 텍스트 라벨만 사용(5개 탭 모두 짧은 한글 라벨로 아이콘 없이도 판별 가능). 설정 진입용 톱니바퀴 아이콘만 예외적으로 Lucide를 사용한다. 검색 아이콘 등 최소한의 UI 글리프가 필요한 곳(`StockSearchBar`)은 **Lucide**(MIT, CDN: `unpkg.com/lucide-static`)에서 최소한만 대체 사용 — 자체 아이콘 세트가 없어 대체했음을 여기 명시한다. 이모지는 사용하지 않는다(브리프 어조가 건조한 데이터 툴을 지향).

## 로고

제공된 자료에 로고/브랜드 마크가 없다. 로고 자리에는 항상 일반 텍스트("단기매매 신호 대시보드")를 사용하고, 실제 로고를 받으면 교체한다.

## 컴포넌트 (7개 — 브리프 2번 "공용 컴포넌트" 표가 정의한 전체 인벤토리)

`components/core/`
- **DirectionGauge** — 5단계(적극매도·매도·중립·매수·적극매수) 반원 게이지. 탭1의 히어로.
- **ContributionBar** — 지표별 +/- 기여도 중앙기준 막대.
- **StockHeader** — 현재가·등락률·거래량·시가총액·장상태 요약 스트립.
- **CandleChart** — OHLCV 캔들 + VWAP 오버레이 + 거래량 서브패널, mini/full 모드.
- **IndicatorTable** — 지표명·현재값·신호(매수/매도/중립) 테이블.

`components/navigation/`
- **TabNavigation** — 상단 탭 네비게이션(5개 탭: 종합 신호+매매계획·기술적 분석·수급·매크로/시장·관심종목). 설정은 탭이 아니라 우측 상단 톱니바퀴 아이콘 → `ui_kits/_shared/SettingsPanel.jsx`의 슬라이드 패널로 진입한다.

`components/forms/`
- **StockSearchBar** — 티커/종목명 검색 + 자동완성.

### Intentional additions
없음 — 위 7개는 모두 브리프 2번 표에 명시된 컴포넌트이며, 이 시스템은 그 외 컴포넌트를 임의로 추가하지 않았다.

## UI 킷

`ui_kits/overview-tab/` — **탭 1 (종합 신호)** 전체 화면. "사? 팔아?"에 3초 안에 답하는 홈: 종목 헤더 → 대형 방향성 게이지(히어로) → 기여도 요약 → 미니 캔들차트 → 신호 히스토리 타임라인 순으로 세로 스택, 여백 넉넉. 검색바에 다른 종목(LG에너지솔루션, 삼성SDI 등)을 입력하면 데이터가 바뀌는 클릭스루 데모.

`ui_kits/technical-tab/` — **탭 2 (기술적 분석)** 전체 화면. 차트 딥다이브. 타임프레임 토글(1분/5분/일봉) + 메인 캔들차트(이동평균선·VWAP·볼린저 오버레이 토글) + 거래량 서브패널 + RSI/MACD/스토캐스틱 오실레이터(접기/펼치기) + 지표 테이블, 고밀도 레이아웃. 차트를 전체화면으로 확대해 그리기 도구·다중 타임프레임을 쓸 수 있는 딥다이브 모드 포함.

`ui_kits/screener-tab/` — **탭 5 (관심종목/스크리너)** 전체 화면. 토스증권 홈 화면의 레이아웃 구조(지수 스트립 · 랭킹 테이블 · 우측 고정 실시간 패널)를 참고해 이 시스템 톤으로 재해석했다 — 색·타이포·카드 스타일은 전부 Terminal Slate 토큰, 매수/매도 체결비율 막대는 국내 관습(매도=파랑 좌측, 매수=빨강 우측)을 따른다. 좌측: 관심종목 칩 + 조건 빌더(정적 데모) + 조건 충족 종목 랭킹 테이블. 우측: 실시간 스코어 랭킹 패널 + 선택 종목 미니차트·근거 요약. 로고·아이콘 등 토스증권 고유 자산은 전혀 복제하지 않았다(레이아웃 구조만 참고).

`ui_kits/flow-tab/` — **탭 3 (수급)** 전체 화면. 국내 단타의 핵심인 "누가 사고파는지"에 집중한 고밀도 2컬럼 레이아웃. 좌측 고정: 호가창(Level 2, 10호가, 매도=파랑 위·매수=빨강 아래). 우측 스택: 외국인·기관 순매수 추이(일별/누적 토글) → 프로그램 매매 동향 → 체결강도 미터 → 거래원 상위 테이블.

`ui_kits/overview-tab/`의 섹션 B — **매매 계획** (구 탭4 리스크/전략, 이제 탭1에 통합). 진입가/ATR·R:R 배수 선택 → 손절가·목표가 자동 산출 → 포지션 사이징(계좌 규모·감당 리스크 %) 순으로 배치한 계획 수립 화면.

`ui_kits/_shared/SettingsPanel.jsx` — 설정 패널(가중치 슬라이더·프리셋·지표 파라미터·알림 임계값·미리보기) + 진입용 톱니바퀴 버튼. 5개 탭 화면이 모두 이 파일을 로드해 우측 상단 아이콘에서 동일한 패널을 연다. `ui_kits/settings-tab/`은 이 패널의 진입 동작만 보여주는 데모 카드.
