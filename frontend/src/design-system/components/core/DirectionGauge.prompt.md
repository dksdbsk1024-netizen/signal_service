5단계(적극매도·매도·중립·매수·적극매수) 반원 게이지로 -100~100 스코어를 시각화하는 방향성 게이지. 탭1(종합 신호)의 화면 주인공으로 가장 크게 쓰인다.

```jsx
<DirectionGauge score={62} size="lg" subtitle="09:32 갱신" />
```

- `size="sm"`으로 워치리스트 카드나 리스트 행 안에 압축 배치 가능.
- 색상은 항상 국내 관습(매수=빨강, 매도=파랑)을 따르며 스코어 부호와 무관하게 이 컴포넌트가 색을 자동 결정한다 — 호출부에서 색을 넘길 필요 없음.
- `showScoreLabel={false}`로 숫자만 남기고 텍스트 라벨을 숨길 수 있다(초소형 배치용).
