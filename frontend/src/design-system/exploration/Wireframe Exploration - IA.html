상단 고정 탭바로 화면 전체를 스와핑. 탭마다 밀도가 다른 현재 구조를 그대로 확장 — 한 번에 한 탭만 보임, 탭1은 여백 넉넉·탭2/3는 촘촘.

탭 → 위치 매핑

탭1~5탭바 클릭 시 body 전체가 다른 탭 콘텐츠로 완전히 교체됨. 탭 간 이동 시 이전 탭 정보는 화면에서 완전히 사라짐 (교차 참조 불가).
설정우측 상단 톱니 → 우측 슬라이드 패널 (탭과 무관하게 항상 같은 위치)
⟶
B안 — 좌측 고정 내비 + 우측 상시 컨텍스트 독
탭을 세로 아이콘 레일로 이동. 어떤 탭을 보든 우측에 스코어·알림 미니 위젯이 항상 떠 있어 딥다이브 중에도 신호를 놓치지 않음.

탭 → 위치 매핑

탭1~5좌측 세로 레일 아이콘으로 전환, 중앙 캔버스만 바뀜. 우측 컨텍스트 독(게이지·알림·커뮤니티)은 탭과 무관하게 항상 고정 노출.
탭5중앙 영역이 관심종목 랭킹+스크리너 테이블로 전환 (레일·독 구조는 동일)
설정레일 하단 톱니 → 동일한 우측 슬라이드 패널
⟶
C안 — 탭 없는 3분할 워크스테이션 (아코디언)
탭 내비게이션 자체를 없앰. 좌/중/우 3열이 항상 동시에 떠 있고, 중앙 열의 아코디언 섹션을 펼쳐/접어 원하는 탭 콘텐츠만 확장 — 여러 탭을 동시에 볼 수 있음.

탭 → 위치 매핑

탭1·2·4중앙 열의 아코디언 3섹션(종합신호/기술적분석/리스크전략)으로 재배치 — 한 번에 하나만 펼치거나 여러 개 동시에 펼침 가능
탭3우측 열에 상시 고정 (호가창·수급) — 탭이 아니라 항상 보이는 패널
탭5좌측 열에 상시 고정 (관심종목·스크리너) — 역시 상시 패널로 승격
